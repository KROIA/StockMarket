## Placeholders

| Tag | Change |
|---:|---|
| ![feature] | TAB and Placeholder API placeholders through the ModUtilities placeholder registry: price, 24h change and 24h volume per trading pair, player open orders and portfolio value, each with a `_raw` variant; slave servers pull the values from the master. See the [placeholder guide](../documentation/user-guide/placeholders.md) |

## Villager Trading

| Tag | Change |
|---:|---|
| ![improvement] | Villager trade data is now stored in the StockMarket data folder (`data/StockMarket/villager_trades.nbt`) instead of vanilla world storage, on master and slave servers; existing worlds are migrated automatically on server start |

## Bug Fixes

| Tag | Change |
|---:|---|
| ![bugfix] | Server tick handlers were not removed on server stop and stacked up after switching singleplayer worlds; the same applied to the BankSystem event listeners (villager trade broadcast, trust sync, ItemID merge) |
| ![bugfix] | JEI integration was never loaded on Fabric because the mod did not register its JEI plugin entrypoint; the plugin also used the BankSystem plugin id instead of its own |
| ![hardening] | The display block price chart is registered in the ModUtilities GUI element registry, so a display GUI rebuilt on the client from a server structure update keeps its chart instead of dropping it |

## Build & Dependencies

| Tag | Change |
|---:|---|
| ![improvement] | Bump BankSystem and ModUtilities dependencies to `1.21.1-2.2.0` |
| ![removal] | Old TAB integration and its `TAB-API` compile dependency |
