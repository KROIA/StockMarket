## API

| Tag | Change |
|---:|---|
| ![feature] | `IPluginMarket` gained `isVirtualOrderbookEnabled()`, `resetVirtualOrderbook()`, and `clearVirtualOrderbook()` |
| ![feature] | `AsyncMarket.FunctionType` gained `ResetVirtualOrderbook` and `ClearVirtualOrderbook` (admin-gated, master-routed) |
| ![feature] | <details><summary>New `IStockMarketIntegration` SPI under `net.kroia.stockmarket.api.integration` for external mods</summary><br>Public service exposed via `StockMarketAPI.getIntegration()` (server-thread only, returns `null` on client). Provides `openMarket(ItemID, MarketConfig)`, `marketExistsFor(ItemID)`, and `closeMarket(ItemID)`, backed by `ServerMarketManager`. `MarketConfig` carries `virtualOrderbookEnabled`, `defaultPrice`, `naturalAbundance`, and `ignorePluginAutosubscribe`; `MarketOpenResult` covers `SUCCESS`, `ALREADY_EXISTS`, `ITEM_BLACKLISTED`, and `FAILED` with an optional reason string. `ServerMarketManager` gained a `createMarketWithConfig(ItemID, MarketConfig)` overload so the initial settings are applied atomically at creation time.</details> |

## UI / UX

| Tag | Change |
|---:|---|
| ![feature] | <details><summary>Per-market Enable Virtual Orderbook toggle in Market Settings</summary><br>New checkbox in the Market Settings widget controls whether the virtual orderbook is active for a market. When disabled, reads return 0 and writes are dropped at the source, so default-volume plugins skip the market entirely.</details> |
| ![feature] | Clear and Reset actions for the virtual orderbook, grouped with the enable checkbox and disabled when it is off |
| ![feature] | Preset editor: per-preset `Virtual Orderbook` and `No Plugin Autosubscribe` checkboxes |
| ![improvement] | Create Market tab: market info panel is now a compact bullet list showing Price / Abundance / Orderbook Enabled / Ignore Plugin Autosubscribe |
| ![improvement] | Overview tab hides Market Open, Market Settings, and Delete when no market is selected |
| ![improvement] | Market Settings and Overview right panels narrowed for better balance |
| ![improvement] | Preset editor tooltips align to the top-right so they render to the left of the cursor; delete button gained a tooltip |
| ![improvement] | Deselect All button in Create Market tab is always enabled |
| ![bugfix] | Trade screen now shows the Market Closed label correctly on initial open |

## Bug Fixes

| Tag | Change |
|---:|---|
| ![bugfix] | <details><summary>Market orders with no liquidity now cancel and unlock reserved funds</summary><br>Buy market orders stashed their reservation as `originalLockedMoney` at lock time; cancel now always calls `unlockRemainingFunds`, which prefers the stashed value so partial fills no longer leak locked money.</details> |
| ![bugfix] | Preset editor no longer NPEs on checkbox `setChecked` during init |
| ![bugfix] | Market Settings widget no longer NPEs on the Virtual Orderbook checkbox during init |
