## Bug Fixes

| Tag | Change |
|---:|---|
| ![bugfix] | Management screen: the market list on the Overview tab showed each market several times after creating markets with "Create selected" |
| ![bugfix] | Stock Market Display: after its market was changed, the chart kept the old market's price range, zoom and timeframe, so the new market's candles could sit outside the visible area; the chart now fits the new market |
| ![bugfix] | Stock Market Display: there was no way to change the market of a display once it was set up. The full-screen chart now has a "Configure Display" button, and sneak + right-click with empty hands opens the setup directly (as on the Bank Display). A display switched to the same market as a touching display now joins it right away |

## API

| Tag | Change |
|---:|---|
| ![bugfix] | Market access API: on the master, the asynchronous market and market manager calls ran on whichever thread called them, so an addon calling them from its own thread could change a market while the server was updating it and crash the server. These calls now always run on the server thread. Called from the server thread, the result is still ready at once; called from another thread, the future completes once the server has run the call |

## UI / UX

| Tag | Change |
|---:|---|
| ![bugfix] | Volatility plugin: the "Volatility Scale" tooltip described much smaller price swings than the plugin makes. It now gives the real range at 0.3 (usually about ±10%, 90% of the time within ±23%, practically never beyond ±42%) and says that the price moves mostly in multi-day trends, about ±2% per hour |
| ![improvement] | Simplified Chinese: more natural wording for 31 texts (trading hours, maintenance mode, commands, order tabs, admin messages), contributed in #39 by luo-zi |
