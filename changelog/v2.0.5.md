# v2.0.5 — 2026-07-25

Build fix release: restores the BankSystem dependency on the fabric build.

## Build & Dependencies

| Tag | Change |
|---:|---|
| ![bugfix] | <details><summary>Fabric build now declares its BankSystem dependency</summary><br>The fabric <code>build.gradle</code> was missing both the local <code>flatDir</code> entry pointing at BankSystem's fabric <code>build/libs</code> and the matching <code>modImplementation("com.github.KROIA.BankSystem:banksystem-fabric:$rootProject.banksystem_version")</code> declaration, so fabric compiles could not resolve BankSystem classes. The two missing lines were added, mirroring the ModUtilities setup that was already present.</details> |
