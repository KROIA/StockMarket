# v2.1.0 — In Development

Companion release to BankSystem 2.1.0 and its company feature. StockMarket gains a public integration SPI so external mods can create, pause, resume and delete markets in-process, and the trading UI now understands company shares — a Commodities / Companies filter, BankSystem share display names, and tinted share icons throughout. Also: a per-market virtual orderbook toggle with Clear / Reset actions, and preset editor improvements including an inventory picker for items carrying data components.

## API

| Tag | Change |
|---:|---|
| ![feature] | <details><summary>New `IStockMarketIntegration` SPI under `net.kroia.stockmarket.api.integration` for external mods</summary><br>Public service exposed via `StockMarketAPI.getIntegration()` — server-thread only, returns `null` on a client-only JVM. Full surface: `openMarket(ItemID, MarketConfig)`, `marketExistsFor(ItemID)`, `closeMarket(ItemID)` for lifecycle, plus `setMarketOpen(ItemID, boolean)` / `isMarketOpen(ItemID)` for pausing and resuming trading on an existing market without deleting it.<br><br>`MarketConfig` carries `virtualOrderbookEnabled`, `defaultPrice`, `naturalAbundance`, and `ignorePluginAutosubscribe`; `MarketOpenResult` covers `SUCCESS`, `ALREADY_EXISTS`, `ITEM_BLACKLISTED`, and `FAILED` with an optional reason string. `ServerMarketManager` gained a `createMarketWithConfig(ItemID, MarketConfig)` overload so initial settings are applied atomically at creation time.<br><br>**Pausing is destructive:** `setMarketOpen(subject, false)` cancels every open *player* order — refunding locked balances through the banking system, bot orders untouched — and hides the market from the trade screen, since `GetAvailablePairsRequest` filters on the flag. Price history survives; reopening brings the market back with an empty order book. `isMarketOpen` returns `false` both when the market is closed and when no market exists, and `setMarketOpen` is a no-op for an unknown subject.</details> |
| ![feature] | `IPluginMarket` gained `isVirtualOrderbookEnabled()`, `resetVirtualOrderbook()`, and `clearVirtualOrderbook()` |
| ![feature] | `AsyncMarket.FunctionType` gained `ResetVirtualOrderbook` and `ClearVirtualOrderbook` (admin-gated, master-routed) |
| ![feature] | Client-side `ShareVisualHelpers` wraps BankSystem's `IBankSystemVisualLookup` — null-safe `getShareVisualsOrNull(ItemID)` returns display name and icon for share markets, cache-cold safe |
| ![feature] | `StockMarketModBackend.getClientInstances()` accessor exposes the client-side singleton for consumer helpers |

## UI / UX

| Tag | Change |
|---:|---|
| ![feature] | <details><summary>Shared Commodities / Companies filter on the trading block</summary><br>A segmented control sits directly below the Item/Money · Item/Item mode buttons, making the selection flow `mode → group → item`. The filter applies in **both** modes — money mode through the favorites bar, and Item/Item pair mode by driving the pair selector's item split from the same shared state. Per-group counts are shown on the buttons; grouping is driven by `ShareVisualHelpers`. The pair selector keeps its sort control (name, price, shares issued, 24h volume).</details> |
| ![feature] | <details><summary>Per-market Enable Virtual Orderbook toggle in Market Settings, with Clear and Reset actions</summary><br>A checkbox in the Market Settings widget controls whether the virtual orderbook is active for a market. When disabled, reads return 0 and writes are dropped at the source, so default-volume plugins skip the market entirely. Clear and Reset actions (sticky-clear semantics) are grouped with the checkbox and disabled while it is off.</details> |
| ![feature] | <details><summary>Preset editor: inventory picker for items with data components</summary><br>A "+ From Inventory" button opens a picker of the player's current inventory keyed on `ItemStack` including data components, so component-carrying items such as stamped shares — unreachable from the flat registry list — can be selected. Laid out as vanilla-style 3×9 main + 1×9 hotbar grids with 18px slots and visible slot borders. Both item pickers gained a close button and are mutually exclusive.</details> |
| ![feature] | Preset editor: per-preset `Virtual Orderbook` and `No Plugin Autosubscribe` checkboxes |
| ![improvement] | Trade screen header, orderbook column headers, favorites labels, and favorite-button tooltips prefer the BankSystem share display name over the raw ItemID name, with self-healing fallback while the cache warms |
| ![improvement] | Pair selector rows for share markets render the tinted preset share icon via BankSystem's `IShareIconRenderer` when available, falling back to the vanilla ItemStack renderer |
| ![improvement] | Create Market tab: market info panel is now a compact bullet list showing Price / Abundance / Orderbook Enabled / Ignore Plugin Autosubscribe |
| ![improvement] | Overview tab hides Market Open, Market Settings, and Delete when no market is selected |
| ![improvement] | Market Settings and Overview right panels narrowed for better balance |
| ![improvement] | Preset editor: "+ Add Item" list height constrained so it no longer overlaps the Save Changes button row |
| ![improvement] | Preset editor tooltips align to the top-right so they render to the left of the cursor; delete button gained a tooltip |
| ![improvement] | Deselect All button in Create Market tab is always enabled |

## Bug Fixes

| Tag | Change |
|---:|---|
| ![bugfix] | <details><summary>Market orders with no liquidity now cancel and unlock reserved funds</summary><br>Buy market orders stashed their reservation as `originalLockedMoney` at lock time; cancel now always calls `unlockRemainingFunds`, which prefers the stashed value so partial fills no longer leak locked money.</details> |
| ![bugfix] | Preset editor no longer crashes with a `ConcurrentModificationException` when clicking an item in a picker — mode-exit and preset mutation are deferred to the next tick so the children list is not mutated during click dispatch |
| ![bugfix] | Trade screen now shows the Market Closed label correctly on initial open |
